# 教材与本地学习资料：按主题选书

本页把书架照片中的教材与本地学习资料接入现有主题。优先选能补足数学先修链、能确认身份和范围、且与分析／代数／概率／方程／优化直接相关的资料；算法和 Python 资料作为实践补充。推荐用途是本项目的学习安排，不是教材内容已经全部审读的结论。

核对日期：2026-10-05。共记录 **31 条来源记录：25 条纳入、2 条待确认、3 条暂缓、1 条排除**。纳入项中的L07、L08为身份部分确认的暂定入口，引用前须补核。上、下册按一套书记录，照片和本地来源分别记账，不等于31本不同教材。逐条字段见 [书目证据表](book-evidence.tsv)，外部入口的实际读取状态见 [来源核查表](book-sources.tsv)。

本地筛选以 `学习资料` 中常见文档格式的路径清单为起点，排除 HCPpipelines 软件树、notion 导出与 AppleDouble 辅助文件；对 `学习书籍/数学教材` 及算法／Python 候选定点检查。共发现419个文档路径，详细读取15份候选PDF的有限前页和元数据，选入其中13份。没有审读所有课件、软件手册或影像示例数据。

## 身份与证据边界

- 照片：可见书脊可支持书名和部分版次，不能支持整本阅读、版本ISBN或精确章节页码。P09与P14留在待确认表，不推断作者。
- 本地：只检查有限封面、扉页、版权、目录和前言；扫描本未做全文OCR。L07与L08缺少身份前页，推荐是暂定的，使用其内容引用前先补核版权页。
- 外部：正文读取、检索摘要和仅能用JavaScript访问的目录分别标注；来源表不把检索命中写成全文可读。书码／账号限制仍按原平台规则。
- 版本：Matrix Cookbook本地2008版与外部2012版、Python数据分析中文第二版与作者英文第三版，独立保留。照片第三／第四版不会自动升级为网页现行版。
- 学习：本轮没有运行实验、安装旧依赖、核验全书证明或复算统计。参考书链接是学习入口，不是本仓库所有现有结论的已审计来源。
